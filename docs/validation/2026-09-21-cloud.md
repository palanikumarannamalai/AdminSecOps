# Microsoft 365, Azure and Intune control review — 2026-09-21

Scope: all 30 controls exported by the M365 (14), Azure (12) and Intune (4) libraries. Reviewed metadata, decision branches, dataset limitations and regression tests against the primary sources below. Sources were accessed **2026-09-21**; this is a review date, not an assertion that the publisher updated every page that day.

`Aligned` means the stated, limited configuration check is supported by the cited guidance. `Changed` means this review corrected logic or misleading language. `Needs evidence` identifies a material limit to stronger conclusions. None means certification, full baseline implementation, tenant safety, or confirmation that a configured policy is effective in live traffic. FAIL represents the tool's stated configuration requirement, not a legal compliance determination. Runtime missing, failed or partial datasets must not become a clean pass.

## Baseline mapping limits

The [official CISA SCuBA baseline repository](https://github.com/cisagov/ScubaGear/tree/main/baselines) is the authority for baseline IDs and versions. Existing historical mappings (especially MS.DEFENDER, now moved toward Security Suite) are traceability hints pending a pinned current-release crosswalk. This review does **not** certify every historical mapping ID. Existing partial mappings for sharing and DMARC remain explicitly partial; SPF softfail acceptance is also weaker than a strict baseline claim.

NIST SP 800-53 mappings identify related control families/objectives; the technical checks do not establish organizational implementation of those controls. Evidence about governance, exceptions, operation over time, effectiveness, and assessment scope remains required. Missing scope evidence is called out above rather than silently expanding a narrow PASS into whole-tenant assurance.

## Regression verification

Tests cover missing DKIM status, conservative DMARC inheritance, potential NSG deny shadowing, TLS configuration vs negotiated protocol, unknown Intune assignment targets/platforms, Office365 exclusions and hybrid-join wording. The scoped cloud suites passed: **14 files, 210 tests**. `npx tsc -b packages/controls --pretty false` passed. Changed control definitions have version 1.0.1. No customer tenant or Azure settings were changed by this review.

Historical CISA Defender mappings on AUD-001/MDO-001 and SPF partial coverage are now also labelled directly in control metadata, so the UI/report mapping is qualified, not only this review document.
