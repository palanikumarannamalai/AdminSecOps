# Testing

All tests run offline with sanitized, fictional data. No tenant or domain access is needed.

## Commands

| Command | What it runs |
|---|---|
| `npm test` | Vitest: all TypeScript unit, integration, fixture and end-to-end tests (node + web projects) |
| `npm run test:ps` | Pester tests for the PowerShell collectors (`scripts/Invoke-PesterTests.ps1`) |
| `npm run lint` | Typed ESLint with security rules |
| `npm run lint:ps` | PSScriptAnalyzer over the collectors |
| `npm run typecheck` | `tsc -b` for packages/apps, test typecheck, web typecheck |
| `npm run build` | Production build of packages, API, CLI and web |
| `npm run scan:secrets` | Repository secret / hygiene scan |
| `npm run verify` | lint + typecheck + test + build + secret scan |

## Test layers

| Layer | Location | Purpose |
|---|---|---|
| Core unit tests | `packages/core/src/*.test.ts` | Safe JSON, hashing, secret detection, redaction, errors |
| Evidence tests | `packages/evidence/src/evidence.test.ts` | Hostile ZIPs (traversal, absolute paths, symlinks, duplicates, zip bomb, limits), manifest/hash/size verification, secret rejection, envelope mismatch, schema errors without value leakage |
| Engine tests | `packages/engine/src/engine.test.ts` | Evaluation semantics, prioritization, determinism, comparison |
| Control tests | `packages/controls/src/library/**/*.test.ts` | Fixture-based tests per control through the real schemas and engine |
| Library invariants | `packages/controls/src/library/library.test.ts` | Every control: NOT_ASSESSED on empty/failed evidence, NOT_APPLICABLE on not-applicable evidence, complete guidance, has a dedicated test |
| Reporting | `packages/reporting/src/reporting.test.ts` | Escaping/XSS, CSP, required sections, determinism |
| API integration | `apps/api/src/server.test.ts` | Upload end to end, DNS rebinding, CSRF, cross-origin, size limits, ID traversal, persistence, reports |
| CLI | `apps/cli/src/cli.test.ts` | assess/validate/compare/controls/datasets |
| Web | `apps/web/src/**/*.test.tsx` | API client, finding page sections and escaping, filters, compare, upload validation |
| Fixtures | `tests/fixtures.test.ts` | Sample packages verify, are deterministic, and assess without errors |
| End to end | `tests/e2e-pipeline.test.ts` | ZIP -> validation -> inventory -> controls -> findings -> prioritization -> reports -> drift |
| Collector contract | `tests/collector-contract.test.ts` | Runs the PowerShell collector in replay mode and validates its package with the engine (skipped if `pwsh` is absent) |
| Generated docs | `tests/generated-docs.test.ts` | DATA-COLLECTION.md and CONTROL-CATALOG.md are current |
| Collectors | `collectors/powershell/tests/*.Tests.ps1` | Envelope/manifest/hash writers, secret scanner, read-only static analysis, replay end to end |

## Fixtures

`fixtures/assessments/{contoso,contoso-followup,fabrikam}` are generated by
`npm run fixtures` from `scripts/fixtures/`. The generator is deterministic; the fixture
test fails if committed files differ from regenerated output.

## What is not tested

Live collection against real Microsoft services and Active Directory cannot be tested in
this repository. Collector logic is exercised with recorded, sanitized API responses
(replay mode). See KNOWN-LIMITATIONS.md.
