# Security policy

AdminSecOps processes sensitive security configuration locally. Do not attach evidence
packages, generated reports, tenant identifiers, logs, screenshots, credentials or tokens
to a public issue.

Report a suspected vulnerability privately by emailing `mail@palanikumar.net` with the
subject `AdminSecOps security report`. Describe the affected version, the security impact
and safe reproduction steps using synthetic data. Do not send live tenant evidence unless
an encrypted transfer method has been agreed separately.

Only the latest code on the repository's default branch is supported during the public
beta. See [docs/SECURITY.md](docs/SECURITY.md) and
[docs/THREAT-MODEL.md](docs/THREAT-MODEL.md) for the implementation security model.
